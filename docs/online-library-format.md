# 在线稿件库接口

从稿件库右上角三个点菜单打开“在线链接设置”，或在“设置 → 稿件 → 从备份恢复”下方进入同一设置，填写接口地址并保存。保存后立即同步，以后每次启动应用也会自动更新；稿件库顶部的“更新”按钮可手动刷新。未配置链接时不会发起请求。

接口使用 HTTP GET，直接返回 UTF-8 JSON，建议响应头为 `Content-Type: application/json; charset=utf-8`。推荐 HTTPS，也支持局域网 HTTP。无需 CORS；本应用不发送 POST、录音或本地稿件，不配置额外的认证请求头。

```json
{
  "version": 1,
  "scripts": [
    {
      "id": "intro-001",
      "title": "开场稿",
      "content": "# 开场\n\n大家好，欢迎来到今天的分享。\n[停顿，微笑] 接下来介绍提词器。",
      "speechLang": "zh"
    }
  ]
}
```

[可直接使用的 JSON 示例](online-library-example.json)

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| version | 整数 | 必填，固定为 1 |
| scripts | 数组 | 必填，最多 500 篇，可为空 |
| id | 字符串 | 必填，同一地址下唯一且长期保持不变，最多 128 字符 |
| title | 字符串 | 必填，非空，最多 200 字符 |
| content | 字符串 | 必填，非空，最多 100000 个 UTF-16 字符单元；换行用 JSON 的 `\n` 转义 |
| speechLang | 字符串或 null | 可选：`zh`、`en`；`auto`、null 或省略表示跟随应用设置 |

`content` 支持现有稿件格式：`# 标题`、`**加粗**` 和 `[舞台备注]`。整个响应最多 8 MiB；单篇正文按解码后的内容计算长度。请不要再包一层 `data` 或返回 HTML 网页。

相同接口地址和相同 `id` 对应同一篇本地缓存稿件，重复同步不会新增副本；标题、正文或语音语言变更后会更新缓存。在线稿件的本地编辑会在下次同步时被服务端内容覆盖，需要独立修改时请先创建副本。服务端删掉稿件、切换地址、清空链接或网络失败均不会自动删除已缓存稿件。

同步不会打断正在运行的提词器；正在朗读的版本保留到重新打开稿件。语音识别继续离线运行。请保持接口地址稳定，地址变化会被视为另一个稿件来源。
